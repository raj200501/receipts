# Grading policy

These are the rules the gradebook implements. Questions go to the course coordinator.

## Categories

| Category | Weight |
| --- | --- |
| homework | 30 % |
| quizzes | 20 % |
| project | 20 % |
| exams | 30 % |

A student's percentage in a category is the points they earned divided by the points
possible, over the assignments that count in that category.

## Missing and excused work

- Missing work (an empty `points` value) counts as zero points out of the assignment's
  maximum.
- Excused work (`EX`) does not count at all: neither its points nor its maximum are
  part of the category.
- A category in which none of a student's assignments counts (for example because all
  of them are excused) does not count for that student: its weight is shared among the
  student's other categories in proportion to their weights. A student excused from
  every quiz is graded on homework, project, and exams with weights 30/80, 20/80, and
  30/80.

## Final percentage and letters

The final percentage is the weighted sum of the category percentages. Reports show it
with one decimal place. The letter grade comes from the final percentage as it is, not
rounded: 89.99 is a B+.

| Letter | Final percentage |
| --- | --- |
| A | 93 and above |
| A- | 90 to below 93 |
| B+ | 87 to below 90 |
| B | 83 to below 87 |
| B- | 80 to below 83 |
| C+ | 77 to below 80 |
| C | 73 to below 77 |
| C- | 70 to below 73 |
| D | 60 to below 70 |
| F | below 60 |
